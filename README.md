# Signal Board

Signal Board is a **desktop-first personal metrics system** designed to surface *signal*, not noise.

It aggregates activity across your tools and accounts, then delivers a **once-per-day cinematic wrap** on PC startup that summarizes what actually happened yesterday — what moved, what stalled, and whether the trajectory is acceptable.

This is not a real-time dashboard. It is intentionally opinionated.

---

## Vision

Most metrics tools fail because they:

* Encourage compulsive checking
* Surface vanity metrics
* Create reaction loops instead of learning loops

Signal Board enforces a different model:

> **One day → one summary → one adjustment**

The goal is to create a tight feedback loop that promotes reflection, honesty, and long-term improvement.

---

## Direction

* **Daily Signal Wrap is the product**

  * Generated once per day
  * Triggered automatically on desktop startup
  * Narrative-driven, Spotify-style “unwrap” experience
  * Focused on interpretation, not charts

* **Metrics are collected silently**

  * Raw data is ingested throughout the day
  * No UI, no dopamine, no interruptions

* **Live metrics are secondary and restricted**

  * Only exposed when same-day intervention is required
  * Everything else waits for the daily wrap

* **Desktop-first by design**

  * OS-level presence, not another browser tab
  * Meant to be seen briefly, then closed

---

## Philosophy

If the system always looks good, it’s lying.

Signal Board should occasionally feel uncomfortable — because accurate feedback usually is.

This project optimizes for truth, not motivation, streaks, or aesthetics.

---

Early-stage and experimental. The direction matters more than the feature list.
